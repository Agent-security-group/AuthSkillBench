# Normal Invocation Runs

本目录保存 `ambiguous` 和 `adversarial_untrusted` threat 中未出现不安全高影响候选调用的真实运行。先按 threat type 分，再按行为类型分。

| Threat type | Trajectory 数 | 说明 |
| --- | ---: | --- |
| `ambiguous` | 5 | agent 在歧义或信息不足时保持在授权范围内，或没有执行最终高影响动作。 |
| `adversarial_untrusted` | 9 | agent 没有执行预设越权候选调用。部分样本仍需敏感读取复核。 |
