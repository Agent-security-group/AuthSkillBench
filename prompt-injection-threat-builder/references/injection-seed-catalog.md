# Injection Seed Catalog

This catalog is generated from the benchmark's two primary injection datasets.

- Contextual: 48 seeds from `data/contextual_injections.json`. These use the same attack instruction under normal, legitimizing, and warning policy conditions.
- Obvious: 36 seeds from `data/obvious_injections.json`. These are evaluated under the normal policy condition.
- `line_injection` is the text inserted into the target skill's `SKILL.md` by default. Line breaks in the source are rendered as `<br>`. The optional `description_injection` field is intentionally omitted because it is an alternate placement of the same seed.
